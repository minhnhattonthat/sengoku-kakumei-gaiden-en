# Skill gotchas

One line per gotcha: the skill reference it belongs in, then the fact.

- scripts/fetch_emu.py + references/setup.md: `fetch_emu.py gba-bios` 404s; retrobios renamed the file to `bios/Nintendo/Game%20Boy%20Advance/GBA_bios.rom` (same sha1 300c20df6731a33952ded8c436f7f186d25d3492). Downloaded by hand with curl.
- references/graphics.md §Survey: an Orca worker can't spawn reviewer subagents; `codex exec -s read-only -i sheet.png ...` per chunk of 7 sheets in parallel worked for the static sweep (`tools/re_survey_codex.sh`). Labelling sources per 16 KB made its answers usable; one label per 500 KB region did not.
- references/graphics.md §Survey: `tiles.py render` takes one file; a multi-source deduped sheet with offset labels (`tools/re_tilesheet.py` here) would be worth adding to the skill.
- SKILL.md Step 0.2: in this Orca worker session the plugin's guard hook was not loaded (canary not blocked). Adding the `hooks` block to `.claude/settings.json` with `$HOME/.claude/plugins/marketplaces/retro-translation/...` took effect immediately, mid-session.
- references/emulator-qa.md: Mesen shares <exe>/Saves between runs; a game save written by one run turns later cold boots into Continue. warp.lua wipes SRAM via emu.memType.gbaSaveRam at start. Also 8 parallel Mesen runs exhausted memory on this machine; use --jobs 3.
- scripts/sheet.py: `sheet.py a.png --compare b.png --crop ...` printed and drew only one tile (a.png) here; and a dir of non-`f<frame>.png` files (warp's `scene_<name>.png`) gives "No f<frame>.png matched". Worked around by copying to f%06d.png names (`warp.py --proof`).
- references/emulator-qa.md §Debug tool: event shots timed by a fixed hold landed on fades/black about a third of the time with A mashed; timing the shot off the game's dialogue-list loader (on_exec, mashing stopped, +150 frames) gave a text page every time. Worth suggesting in the skill as the default for cutscene scenes.
- references/emulator-qa.md §Debug tool: a mode-byte proof (`expect=MODE`) passed for a scene that really reset the game (stage init crashed, boot code re-ran, the RAM mode byte stayed stale at 29). Proof needs a look at the shot or a reset detector (e.g. on_exec on the boot task init); a probe logging pc, DISPCNT and mode every 60 frames found it in one run.
- Claude Code reaps background shells under memory pressure; a ~1 h `warp.py --jobs 2` run was killed twice because another repo's 20 Mesen.exe (~300 MB each) were running. `warp.py --proof-only` now rebuilds the proof sheets from scene dirs already on disk, so a split run can resume by scene names.
- references/platform-gba.md: Sengoku Kakumei Gaiden mixes encodings: pointed script text is EUC-JP but item/technique names are Shift-JIS fixed records; scan every encoding, not just the first one that hits.
- references/platform-gba.md: font entry layout guessed from the bytes (rows at +4) was off by one; the draw routine read rows from +6. Read the draw routine's source offset before writing glyphs.
- references/emulator-qa.md: context-mode's hook truncates Bash/Read output above ~5 KB; write disassembly to work/ files and read them in slices.
- references/pipeline.md (free space): the 0xFF fill at the end of an 8 MiB GBA ROM was not free: a buggy CpuSet (count 0x34BB4) streamed 431 KB of it into palette RAM, and its last 1 KB of 0xFF made a page white. Anything written there broke one scene only. Trap-fill the free space and tour every scene before using it; to find the reader, a ROM read hook that lands in the BIOS (pc < 0x4000) means a SWI copy: log SWI args.
- assets/batches.py: the glossary check compared terms against the English as stored, so a name the wrap code split across lines ("Nobutsuna|nKamiizumi") read as missing; this repo's copy flattens line breaks and codes first (`flat` in `problems`). Also: its selftest used `[n]`/`[var]` tokens and had to be rewritten for a `|n`/`%d` game, and "no Japanese letters" entries (arrows ↑↓) need excluding in `needs_english`.
- references/translation.md (fitting): for a 3 x 24-letter page, word-wrapped English overflowed at ~60+ letters about one line in four; aim at <= 55 letters per page when drafting, and let `batches.py` wrap (this repo's `wrap()`), fixing overflows with a `fix` overlay file rather than re-writing the batch.
- references/graphics.md (name entry): a kana grid whose name is stored as table indices and printed through the font needs no code change: redraw the grid picture and the font entries of those kana as Latin letters (English text no longer uses kana glyphs). The BG tilemap may be built at run time (not in ROM, not in any LZ block): capture it once from a ppu dump into a data file.
- scripts/vramfind.py: needs the decompressed LZ blocks as a directory; a repo helper that writes every block (`tools/lz_dump.py` here) should be standard, and `--lo/--hi` want hex (a decimal value silently scans the wrong range).
- references/pipeline.md §Checks (stale readers): a whole-ROM word scan for pointers into moved strings hits sound-sample and LZ77 bytes (14 noise words on GBA, 13 mid-string); scope it by rom-map regions and record the exclusion.
- references/emulator-qa.md §Text coverage: per-scene coverage of list-drawn text (menus, item descriptions, map help) is cheapest by stepping the page index at the draw call (a Lua on_exec that rewrites the index register on every redraw) rather than by cursor routes; the list itself is read once at load, so hooking its read sees nothing. Gate the stepping by frame (boot draws eat the first pages). A coverage-runs merger per bank (tools/cover_report.py here) and a waiver generator that refuses unexplained ids (tools/waivers.py) are worth making standard.
- scripts/qa_gate.py init: never drops an id whose sheet no longer exists (a re-tour with fewer pages leaves `missing` rows), so `todo` hands them to reviewers who can only flag "PNG missing"; init (or a `prune` verb) should drop or report ids missing from every listed dir. Here: 8 stale rows answered `ok` in `verdicts/recheck_1.tsv`.
- scripts/qa_gate.py: a graphics-only hotfix after the reviewers' run (a label shifted 1 px) invalidates nearly every tour sheet when the label is on the new-game path; `waive` plus targeted re-shots is the only way out, so a gate that compares only the frames whose pixels changed would save a whole re-tour.
- references/pipeline.md §Release (and translation.md §Review): the story pass and polish pass come after the final tour, and a relocating inserter that packs moved strings in order (plus a pair/DTE table rebuilt from all text) shifts every later string on one edit, voiding all textcover logs (353 of 1037 moved here for 10 edits). Freeze the toured build's relocation slots and pair codes (this repo: `data/text_layout.tsv`, `build.py freeze-layout`), so a late edit moves only itself; then re-shoot just the scenes that show edited strings.
- scripts/qa_gate.py waive: no `--help` for subcommands; the story pass writes `fixed` after applying a re-review's Minors, which needs a newer verdict file than the chapter's `init` time (write it after `init`).
